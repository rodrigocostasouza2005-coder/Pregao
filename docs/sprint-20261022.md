## Ações que dependem do dono do repositório

1. **Criar o secret `GROQ_API_KEY`** em Settings → Secrets and variables → Actions. Sem
   ele não há resumo nem tradução no Morning Call (passo a passo no `MANUAL.md`).
2. **Configurar o disparo externo** (cron-job.org → `workflow_dispatch`, `MANUAL.md` →
   "Disparo externo dos agendamentos"). É a única correção do horário: o GitHub entregou os
   disparos das 08h entre 12:55 e 14:06 BRT em 21/10.
3. **Definir `EMAIL_TO`** (ou decidir outro destino) para os alertas do Radar de Quedas.
   Hoje todo alerta falha no envio e o job fica vermelho.
4. Conferir o provedor SMTP: o próximo erro vai dizer a etapa. Se for "envio da
   mensagem", o servidor está demorando para aceitar o anexo; nesse caso vale considerar
   o Resend, que o workflow já suporta.

```
pip install -r requirements.txt pytest
python -m pytest -q
```

Para conferir o efeito em produção, abrir a próxima execução de **Radar e Morning Call** no
Actions e procurar a linha `texto: N cache exato, N pela URL da fonte, N gerado(s) agora, N só
manchete`.
